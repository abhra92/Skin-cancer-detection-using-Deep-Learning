The PDFs were text-extracted locally with `pypdf`; every supplied PDF was readable. Duplicate PDF copies were deduplicated by SHA-256 for the paper-level review.

## 1. Research problem and question grounded in the materials

The supplied research-question document identifies three recurring concerns: (i) class imbalance and minority-class sensitivity, (ii) comparisons that change architecture, preprocessing, and training at once, and (iii) uncertain transfer across dataset sources. The supplied notebook and a number of the primary PDFs use HAM10000, usually with seven diagnosis labels, while several papers recast the same images into a binary task or a different subset of classes. Those task definitions are not directly comparable.

A narrow, executable question consistent with the supplied materials is:

> **On a fixed, lesion/patient-disjoint HAM10000 seven-class split, how does inverse-frequency class-weighted cross-entropy compare with unweighted cross-entropy for macro-F1 and per-class recall, using the same train-only augmentation and training protocol for a small CNN and a compact pretrained CNN?**

This is a planned question only. It was **not answered experimentally** in this workspace because no HAM10000 images or metadata were supplied.

## 2. Methodology, training, and metrics observed in the papers

| Theme | Evidence in supplied papers | Design implication for this project |
|---|---|---|
| Data | HAM10000 is a recurring seven-diagnosis dermoscopic benchmark; ISIC 2016–2020, PH2, DermIS, MSK10000, and other collections also appear. Some papers merge corpora or re-map diagnosis labels. | Keep the present experiment to the explicitly defined HAM10000 seven-class task. Do not compare a binary or four-class result as though it were seven-class. External evaluation needs an independently audited dataset and a predeclared label mapping. |
| Preprocessing | Resizing, normalization, augmentation, lesion segmentation, super-resolution, and hair/artifact removal are all explored. Some studies combine these with architecture or loss changes. | Use one simple, documented resize/normalization pipeline first. Split before any stochastic augmentation; restrict random transforms to the training loader. Do not add segmentation or synthetic data in the first controlled comparison. |
| Models | Conventional CNNs and transfer-learned ResNet, DenseNet, EfficientNet, MobileNet, VGG, Inception, Xception, and newer ConvNeXt families are represented. A smaller group tests ViTs, CNN–ViT hybrids, graph networks, ensembles, and multi-task segmentation/classification. | A compact from-scratch CNN plus a light transfer model creates an interpretable baseline/transfer comparison within the available compute budget. Larger ViT/GNN/dual-branch and ensemble systems are not justified on the current two-core/no-GPU runtime. |
| Imbalance methods | Papers investigate augmentation, oversampling/SMOTE-Tomek, class weighting/focal loss, and GAN-generated images. These approaches change different parts of the data or objective and are not interchangeable. | First vary one imbalance intervention—training-split inverse-frequency loss weights—while holding the split and model fixed. Keep any later focal-loss/oversampling/GAN study separate and pre-registered. |
| Evaluation | Accuracy is commonly reported; several papers additionally report precision, recall/sensitivity, F1, specificity, ROC-AUC, or segmentation Dice/IoU. Metrics and class definitions differ between papers. | Report macro and weighted precision/recall/F1, accuracy, balanced accuracy, class-wise sensitivity/specificity, ROC-AUC/PR-AUC where defined, and raw/normalized confusion matrices. State the averaging convention. |
| Validation and limitations | The supplied set includes cross-dataset evaluations and multi-dataset comparisons, but many papers report a single benchmark, different class maps, or substantially more complex methods. Dataset duplicates and differences in label granularity are visible concerns in the supplied material. | Use lesion/patient/hash-grouped train/validation/test splits. Select on validation macro-F1 only; evaluate test once. Do not claim clinical readiness or external generalization from an internal split. |

### Candidate research gap

The defensible gap for this small project is not “no skin-cancer model exists.” The supplied literature already contains many CNN and transfer-learning systems. A narrower unresolved comparison is whether a **single, explicitly defined, non-synthetic imbalance intervention** improves macro-F1 and rare-class recall under the same split and training conditions. The source set does not establish a universally best imbalance method; the available studies differ in datasets, label maps, splits, and combinations of interventions.

### Why no classical raw-image baseline is planned

Logistic regression, SVM, and tree models are not meaningful competitors on unengineered raw RGB pixels at this scale. A classical baseline would require a declared feature representation (e.g., handcrafted color/texture features or a frozen CNN embedding) and would then answer a different question. No classical model is forced into the present matrix.

### HAM10000-folder sources

1. **Himel et al. (2024), “Skin Cancer Segmentation and Classification Using Vision Transformer for Automatic Analysis in Dermatoscopy-Based Noninvasive Digital System.”** Source: `HAM10000/International Journal of Biomedical Imaging - 2024 - Himel - Skin Cancer Segmentation and Classification Using Vision.pdf`. The supplied paper describes HAM10000 recast into benign/malignant labels and combines lesion segmentation with ViT-family classifiers. It reports segmentation overlap and classification metrics. This binary task and its segmentation labels are not equivalent to the original seven-class task. The authors identify population/data extension as future work.
2. **Wang & Chen (2026), “Comparative Study of Transfer Learning Strategies for Multi-Class Skin Lesion Classification: Architectures, Fine-Tuning, and Data Augmentation.”** Source: `HAM10000/paper_051af425744157c1b9fec6b63445a483.pdf`. Compares ResNet50, DenseNet121, and EfficientNet-B0 with multiple fine-tuning and augmentation strengths on HAM10000; the supplied abstract reports AUC/F1 and a Welch-test comparison. The abstract also contains inconsistent headline validation summaries, so its numbers are not imported into this project and should be checked against the full protocol before citation.
3. **Tahir et al. (2023), “DSCC_Net: Multi-Classification Deep Learning Models for Diagnosing of Skin Cancer Using Dermoscopic Images.”** Source: `HAM10000/paper_199ed56ea8cd5ab18d0664abadcb21fc.pdf`. Proposes a CNN for four diagnostic groups and reports experiments on ISIC 2020, HAM10000, and DermIS, with SMOTE-Tomek used for imbalance. The four-class target and mixed-source setup differ from the proposed seven-class HAM10000 task.
4. **Vieira, Mendonça & Morgado-Dias (2025), “Deep Learning Approaches for Skin Lesion Detection.”** Source: `HAM10000/paper_20559e74133d51fc8d04593c678e7ea7.pdf` (also copied under `ISIC 2019/`). Benchmarks 38 standard CNN architectures from ten families with transfer learning on the seven-class HAM10000 task and includes cross-database testing using ISIC 2019 plus a mobile prototype. This supports reporting both class-aware metrics and dataset-shift limitations; its architecture sweep is broader than the compute budget here.
5. **Su et al. (2024), “A GAN-based Data Augmentation Method for Imbalanced Multi-class Skin Lesion Classification.”** Source: `HAM10000/paper_2b031f6e5e2d57adaa5aea41bcb02368.pdf`. Proposes a two-stage/self-transfer GAN for imbalanced HAM10000 image generation and evaluates image-generation quality as well as downstream classification. The paper is relevant to imbalance but changes the training data-generating process; a GAN is not part of the initial controlled matrix.
6. **Alam et al. (2022), “An Efficient Deep Learning-Based Skin Cancer Classifier for an Imbalanced Dataset.”** Source: `HAM10000/paper_45866f3362a35de084d840bba4f6485e.pdf`. Evaluates CNN backbones on HAM10000 and addresses skewed class counts; the paper reports conventional classification metrics. Its imbalance focus supports macro/per-class reporting rather than accuracy-only model selection.
7. **Dogga, Sivasubramanian & Shanthi (2026), “Hybrid Vision Transformer and Graph Neural Network Model with Region-Adaptive Attention for Enhanced Skin Cancer Prediction.”** Source: `HAM10000/paper_48767bbc04ff53a98a83ccc5c9ccd399.pdf` (also copied under `PH2/`). The supplied PDF describes a ViT–GNN/region-attention method and names ISIC 2020, HAM10000, and PH2 in its evaluation. It is substantially more complex than the compact baseline planned here. Bibliographic/reference details in this supplied 2026 copy should be independently verified before formal citation; this review does not rely on its headline claims.
8. **Musthafa et al. (2024), “Enhanced Skin Cancer Diagnosis Using Optimized CNN Architecture and Checkpoints for Automated Dermatological Lesion Classification.”** Source: `HAM10000/paper_4ae3a46584645ef49c1ffd38ab82bcdf.pdf`. Uses HAM10000, a custom/optimized CNN, and checkpoint/learning-rate controls for lesion classification. It motivates recording checkpoint selection and training configuration; its reported accuracy is not a target or result for this project.
9. **Abu Owida et al., “A Deep Learning-Based Dual-Branch Framework for Automated Skin Lesion Segmentation and Classification via Dermoscopic Images.”** Source: `HAM10000/paper_58d7f048719f5e9fb1139076c0c0769e.pdf` (also copied under `PH2/`). Combines a segmentation branch (modified EfficientNet-B7/ASPP/transformer components in the supplied text) and a DenseNet-121/morphology-based classification branch; the paper names HAM10000, PH2, and ISIC 2016–2018. It reports both segmentation and classification outcomes. The multi-branch architecture and segmentation annotations impose additional compute/data requirements.
10. **Ahmad et al. (2023), “A Novel Framework of Multiclass Skin Lesion Recognition from Dermoscopic Images Using Deep Learning and Explainable AI.”** Source: `HAM10000/paper_7314ac335b105680ad684da95b2777b8.pdf` (also copied under `ISIC 2019/`). Combines pretrained Xception/ShuffleNet features, feature fusion/selection, data augmentation, and Grad-CAM-style explanations; the paper discusses HAM10000 and ISIC datasets. Its multi-stage design motivates keeping interpretability as a later extension, after a simple baseline is reproducible.
11. **Najjar et al. (2025), “Transformer-Aided Skin Cancer Classification Using VGG19-Based Feature Encoding.”** Source: `HAM10000/paper_da5ac31c75ac5fbc8847e742ce77a9c3.pdf` (also copied under `PH2/`). Proposes VGG19 local features plus a ViT and rotation/shift feature-map augmentation; the supplied abstract names MSK10000, HAM10000, and PH2 with different class tasks. These cross-task results should not be pooled as one metric comparison.

## 4. Literature-to-experiment choices

- **Primary label space:** HAM10000 diagnosis labels `akiec`, `bcc`, `bkl`, `df`, `mel`, `nv`, `vasc` (seven classes). Keep binary or four-class papers separate.
- **From-scratch reference:** compact custom CNN. It establishes a transparent baseline and does not presume ImageNet weights are available.
- **Transfer model:** MobileNetV3-Small with ImageNet initialization, chosen over EfficientNet-B0/large ViT/GNN/ensembles for the CPU/RAM constraints. If pretrained weights cannot load, the transfer experiment must fail visibly rather than silently become training-from-scratch.
- **Imbalance comparison:** unweighted cross-entropy versus inverse-frequency weighted cross-entropy computed from the training split only. Same split, seed, augmentation, and optimizer within each model pair.
- **Preprocessing:** resize to 160×160 RGB; ImageNet mean/std; random horizontal/vertical flips and ±15° rotation on train only. This deliberately avoids synthetic image generation, segmentation, and test-derived normalization in the first experiment.
- **Evaluation:** checkpoint on validation macro-F1; held-out test only once. Report macro and weighted precision/recall/F1, accuracy, balanced accuracy, per-class sensitivity/specificity, ROC-AUC/PR-AUC where defined, inference/training time, and confusion matrices.
